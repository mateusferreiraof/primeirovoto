# primeirovoto

# Passo a passo para rodar o projeto localmente:
# Clone o repositório: git clone https://github.com/mateusferreiraof/primeirovoto.git
# Ao abrir o projeto no vscode/terminal, rode o comando: npm install
# Depois rode o comando: npm run dev
# Por último, abra outro terminal (na pasta do projeto) e rode o comando: php artisan serve. O projeto abrirá em: http://localhost:8000/
